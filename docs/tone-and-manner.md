# 문구 톤앤매너

플랜핏 앱 화면(wwit.design 2023-07-24 사례 모음 스크린샷)의 문구 패턴을 읽고, 이 앱에 맞게 옮긴 기준이다. 원문을 베끼지 않고 패턴만 가져왔다.
플랜핏은 운동 습관 앱이고, 이 앱은 스스로 약속을 지키게 하는 앱이라 결이 같다: **곁에서 챙겨 주는 코치**처럼 말한다.

## 1. 목소리

- 기본은 **해요체**. 친근하지만 들뜨지 않는다. 합쇼체(~합니다)는 쓰지 않는다.
- 주어는 대부분 생략한다. 앱이 해 주는 일은 "~해 드릴게요", 사용자가 할 일은 "~해 주세요 / ~해 보세요".
- 느낌표는 칭찬·격려 한 곳에만 (`잘했어요!`). 경고에는 쓰지 않는다.
- 사용자를 다그치지 않는다. 잠금·억제는 벌이 아니라 약속을 지키게 돕는 장치로 말한다.

| 플랜핏에서 본 패턴 | 이 앱에 옮긴 예 |
|---|---|
| 제안은 "~해 봐요/보세요" | 시작 시각과 인증 방법을 정해 첫 과제를 만들어 보세요 |
| 개인 정보를 물을 때 이유 한 줄 + 안심 한 줄 | 장소를 확인하는 인증 때만 한 번 재요. 백그라운드 위치는 쓰지 않아요 |
| 결과 알림은 과거형 한 문장 | 늦었지만 기록했어요 |
| 앱이 하는 약속은 "~드릴게요" | (온보딩·알림 권한 요청에서 쓴다) |

## 2. 길이와 구조

- **한 줄에 한 가지**만 말한다. 같은 화면에서 같은 설명을 두 번 하지 않는다.
- 제목 → 이유 한 줄 → 행동 버튼. 이유가 두 줄을 넘으면 덜 중요한 쪽을 `TIP.` 줄로 내린다.
- 부가 정보는 `TIP. ~` 한 줄로 쓴다 (예: `TIP. 지금 있는 곳이 아니어도 지도에서 고를 수 있어요`).
- 빈 화면은 **무엇이 없는지 + 무엇을 하면 되는지 + 버튼** 세 줄이다 (`아직 등록한 태그가 없어요 / 과제하는 곳에 스티커를 붙여 두세요 / 첫 태그 등록하기`).
- 상태가 배지·아이콘으로 이미 보이면 같은 말을 문장으로 또 쓰지 않는다.

## 3. 버튼

- 행동이 하나로 분명하면 **동사 + 하기**: `지금 인증하기`, `첫 과제 만들기`, `지도에서 고르기`.
- 짧은 확인·취소는 명사 한 단어: `저장`, `확인`, `삭제`, `다음`.
- 대답형 대화상자는 사람 말투로: `네, 맞아요` / `다시 검색`.
- 같은 행동은 화면이 달라도 같은 이름을 쓴다 (예: 홈·잠금 화면 모두 `지금 인증하기`).

## 4. 숫자·단위

- 숫자는 크게, 단위는 작게 붙인다 (`31분`, `2시간 49분`).
- 시간은 24시간제 `14:00`, 기간은 `1시간 30분`.
- 개수는 `N개 허용`, `N개 등록`처럼 숫자를 앞에 둔다.

## 5. 안내·오류

- 무엇이 안 됐는지 + 어떻게 하면 되는지를 한 문장씩. 원인을 사용자 탓으로 쓰지 않는다.
  - ✗ `사진 메타데이터의 촬영 시각이 일치하지 않아요`
  - ○ `사진의 촬영 시각이 맞지 않아요`
- 같은 단어를 한 문장에 두 번 쓰지 않는다 (`위치 권한이 필요해요. … 위치 권한을 허용해 주세요` → `기기 설정에서 위치 권한을 허용해 주세요`).
- 기술 용어(메타데이터, 패키지명, ID)는 꼭 필요할 때만, 괄호로 보조한다.

## 6. 이 앱에서 자주 쓰는 말

| 쓰는 말 | 피하는 말 |
|---|---|
| 인증하기 | 인증하고 해제 / 인증하고 끝내기 (화면마다 다르게 쓰지 않는다) |
| 놓쳤어요 | 실패했어요 (마감 관련) |
| 풀려요 | 해제됩니다 |
| 억제 화면 / 억제 중 | 방해 화면, 페널티 |
| 고르기 | 선택하기 (버튼) |

## 7. 문장 리듬 (휴머나이즈 스캔 기준)

`/humanize-scan`이 실측으로 확인한 AI 티 신호 중 UI 문구에 해당하는 것만 본다.

- **같은 종결 연속(E-2)**: 설명 줄이 모두 `~해요`로 끝나면 일부를 명사형(`매일 · 1시간`)이나 `TIP.` 줄로 바꾼다.
- **연결어미 뒤 쉼표(C-11)**: `~않고, ~` → `~않고 ~`.
- **"A가 아니라 B" 대구(C-8)**: 한 화면에 한 번까지.
- 나머지 산문용 신호(장문 비율 등)는 UI 문구에 적용하지 않는다.

## 8. 줄바꿈

- 한국어는 **어절(띄어쓰기) 단위로만** 줄을 바꾼다. "지나가/요", "문/구가"처럼 낱말 가운데서 끊기면 안 된다.
- 앱에서는 `ui/components/KoreanText.kt`의 `Text`가 한글 글자 사이에 보이지 않는 WORD JOINER(U+2060)를 넣어 처리한다 (CSS `word-break: keep-all`과 같은 효과). 화면 파일은 `androidx.compose.material3.Text` 대신 이것을 import 한다.
- 문구를 쓸 때도 한 줄에 들어가지 않을 만큼 긴 어절(띄어쓰기 없는 긴 합성어)은 피한다.
